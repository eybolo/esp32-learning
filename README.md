# Aprendiendo ESP32

Repositorio de ejercicios para aprender a programar una placa ESP32 con Arduino y PlatformIO. Cada carpeta contiene un proyecto independiente y explora una forma de controlar LEDs.

## Ejercicios

- [01-led](01-led/): encender y apagar un LED.
- [02-led-pwm](02-led-pwm/): cambiar el brillo de un LED con PWM.
- [03-led-fade](03-led-fade/): aumentar el brillo de un LED gradualmente.
- [04-led-fade-secuencia](04-led-fade-secuencia/): hacer una secuencia de brillo con tres LEDs.

Para probar un ejercicio, abre su carpeta como proyecto de PlatformIO, compílalo y carga el programa en la ESP32.
